# Kadirur Website

A responsive, modern single-page website about Kadirur (Kannur, Kerala) with:

- Overview and key facts
- Demographics and education highlights
- Travel and connectivity information
- Popular FAQ-style answers

## Run locally

Open `index.html` directly in a browser, or run a local static server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
